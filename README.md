# KazNEB / ЕНУ Book Downloader

Chrome-расширение (Manifest V3): кнопка **«Скачать PDF»** на страницах просмотра книг
**kazneb.kz**, **nabrk.kz** и **library.enu.kz** (ЕНУ, MegaViewer). PDF собирается прямо в браузере.

## Установка
1. Скачайте `kazneb-extension.zip` из [последнего релиза](../../releases/latest) и распакуйте.
2. Откройте `chrome://extensions`, включите «Режим разработчика».
3. Нажмите «Загрузить распакованное» и выберите папку `kazneb-extension`.

## Использование
Откройте книгу в просмотрщике и нажмите плавающую кнопку «Скачать PDF».
Для ЕНУ число страниц, токен и название книги считываются со страницы автоматически.
